# 📚 Online Exam Monitoring & Integrity Analytics Platform

## 📌 Project Overview

The Online Exam Monitoring & Integrity Analytics Platform is an AI-powered web application developed to improve the security and integrity of online examinations. The system monitors candidates using computer vision and browser activity tracking, helping identify suspicious behavior during exams.

---

## 🚀 Features

- 🔐 Candidate Registration and Login
- 📸 Photo Capture during Registration
- 👤 Face Detection using OpenCV
- 🧠 AI-based Monitoring
- 📊 Analytics Dashboard
- 📝 Session Activity Logging
- 🚨 Suspicious Activity Detection
- 📈 Performance Reports
